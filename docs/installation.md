# Installation

## Stable release

To install SONARE, run this command in your terminal:

```sh
uv add SONARE
```

Or if you prefer to use `pip`:

```sh
pip install SONARE
```

## From source

The source files for SONARE can be downloaded from the [Github repo](https://github.com/iuryrdns/SONARE).

You can either clone the public repository:

```sh
git clone https://github.com/iuryrdns/SONARE
```

Or download the [tarball](https://github.com/iuryrdns/SONARE/tarball/main):

```sh
curl -OJL https://github.com/iuryrdns/SONARE/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd SONARE
uv sync
```
